# Drone Spray Zone Analysis using Multispectral Agricultural Imagery

A geospatial precision agriculture project that identifies crop stress regions from multispectral drone imagery and generates spray prescription zones using NDVI analysis.

This project simulates a simplified agricultural drone analysis workflow where multispectral field imagery is processed to detect stressed vegetation regions requiring intervention such as pesticide spraying or nutrient application.

---

# Problem Statement

Traditional blanket spraying methods result in:

* excessive chemical usage
* increased operational cost
* uneven field treatment
* environmental inefficiency

Precision agriculture systems solve this by analysing crop health spatially and applying intervention only where required.

This project explores how multispectral drone imagery can be converted into actionable spray zones using computer vision, raster processing, and GIS workflows.

---

# What is an Orthomosaic?

An orthomosaic is a geometrically corrected aerial image generated by stitching together multiple drone images into a single top-down georeferenced map.

The multispectral orthomosaic used in this project contains multiple spectral bands including:

* Red
* Near Infrared (NIR)

These bands are used for vegetation health analysis.

---

# NDVI Theory

NDVI (Normalized Difference Vegetation Index) is computed using:

[
NDVI = \frac{NIR - Red}{NIR + Red}
]

Where:

* high NDVI → healthy vegetation
* low NDVI → stressed vegetation

Healthy plants absorb visible red light for photosynthesis while strongly reflecting near-infrared radiation due to internal leaf structure.

# Workflow

## 1. Multispectral Raster Loading

The orthomosaic TIFF was loaded using Rasterio and converted into NumPy arrays.

## 2. Band Extraction

The Red and NIR bands were extracted from the multispectral raster.

## 3. NDVI Computation

Pixel-wise NDVI values were computed using the Red and NIR bands.

## 4. Stress Thresholding

Low NDVI regions were classified as stressed vegetation zones.

## 5. Spray Zone Generation

Binary stress masks were converted into vector polygons using raster-to-vector conversion.

## 6. GIS Export

Detected spray zones were exported as shapefiles for GIS compatibility.

## 7. Interactive Visualization

Spray zones were visualized using Folium as an interactive HTML map.
